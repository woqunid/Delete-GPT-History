# Delete-GPT-History

用于 ChatGPT 网页的第三方 Tampermonkey（油猴）脚本。它提供会话加载、标题或 ID 搜索、批量选择、删除前预览和批量清理，不需要额外的服务器或 npm 依赖。

## 安装

1. 在浏览器中安装 Tampermonkey，并确认它能够在 ChatGPT 网站运行用户脚本。
2. 打开本仓库的 [`main.js`](./main.js)，复制完整代码。
3. 在 Tampermonkey 中新建脚本，用复制的代码替换默认内容，保存并启用。
4. 登录并刷新 `https://chatgpt.com/`。右下角会出现垃圾桶按钮。

已有旧版脚本时，请直接替换原脚本内容，避免同时启用多个版本。

## 使用

1. 点击垃圾桶按钮，打开清理面板；按钮可拖动，位置会保存在当前网站的本地存储中。
2. 点击“加载会话”。加载过程中可以停止；停止或请求失败后，可继续加载，也可以用“刷新”从头获取列表。
3. 按标题或 ID 搜索并勾选记录。“全选当前结果”包含所有匹配结果，包括尚未通过“显示更多”展开的记录。
4. 点击“删除 N 条会话”，核对待删标题后再确认。超过 100 条时，可以分批展开完整的确认列表。
5. 执行结果会分别显示已处理、成功和失败数量。失败项会保留勾选，可点击“重试失败项”再次预览并确认。
6. 删除成功后，可点击“刷新页面同步侧栏”，更新 ChatGPT 自身显示的会话列表。

切换搜索不会清除之前的勾选。面板和确认窗口都会提示搜索结果之外的已选项；“清空选择”会清除全部勾选。

如果只加载了一部分会话就进行删除，原分页位置会失效。“继续加载”会改为“重新加载”，下一次加载从头获取列表，避免因会话移位而漏掉记录。

加载和删除任务互斥。执行期间不能改变选择或重新开始任务。“停止删除”停止调度后续会话；最多 3 条已开始处理的会话仍会继续完成，包括它们的必要重试。关闭面板不会停止正在执行的任务。

按 Esc 退出删除确认或关闭面板。使用帮助和操作详情默认折叠，避免占用列表空间。

## 请求与数据处理

- 使用当前登录会话的令牌，调用 ChatGPT 网页的同源内部接口；令牌只保留在脚本内存中。
- 请求之间至少间隔 250 毫秒，删除最多并发 3 条会话。
- 单次请求超时为 15 秒；网络错误、超时和 HTTP 429/502/503/504 最多额外重试 2 次，并遵循 `Retry-After` 等待时间。
- 遇到 HTTP 401 会重新获取一次登录状态；持续的 401 或 403 会停止调度后续删除。
- 删除请求为 `PATCH /backend-api/conversation/{id}`，内容为 `{ "is_visible": false }`。本工具不提供撤销，不能仅凭这一请求确认服务器永久清除了聊天数据。
- 内部接口可能随 ChatGPT 更新而变化。响应格式异常时会明确报错，而不会将其当作空列表或加载成功。
- 会话标题以纯文本显示；列表分批渲染，操作日志最多保留 100 条。

## 验证

安装 Node.js 后，在仓库目录执行：

```sh
node --check main.js
node --test tests/main.test.cjs
```

测试使用模拟 DOM 和接口，覆盖任务互斥、搜索和确认范围、分页、登录刷新、请求重试、超时、停止任务及失败重试，不访问实际 ChatGPT 账号。
